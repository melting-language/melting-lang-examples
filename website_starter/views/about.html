About

Every page on this site is assembled from small HTML partials chained together in Melt. Each controller builds a Document and calls .append(path, data) once per partial -- head, navbar, page body, footer -- then .build() returns the finished HTML string: 

Document()
    .append("views/partials/head.html", ["title" :=> "Home"])
    .append("views/partials/navbar.html", navData)
    .append("views/home.html", pageData)
    .append("views/partials/footer.html", footerData)
    .append("views/partials/foot.html", objectCreate())
    .build();

Each append() returns this, which is what makes the chaining possible.

Partials can also pull in smaller fragments themselves with {{ include("file.html") }} right inside the HTML -- this page's own <head> includes meta.html for its social preview tags, and the footer below includes social.html for its links. Includes share whatever data was passed to the page that included them.

Routing is Laravel-style, defined in routes.melt: 

Route.get('/about', [AboutController, 'index']);
Route.get('/hello/{name}', [HelloController, 'greet']);

Class.method() calls a method with no instance -- melt classes are already values, so [HelloController, 'greet'] just holds the class itself alongside the method name -- and {name} path segments are captured and passed as positional arguments to the handler via callMethod(controller, methodName, params) -- see the Say Hello page for {name} in action.
